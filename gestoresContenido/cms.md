# Sistema de Gestión de Contenidos

## **CMS**

Es un sistema de gestión de contenidos encargada de crear, editar y administrar
páginas web sin crearlas desde cero.

![cms](imagenes/portada-cms.jpg)

## **Funcionamiento**

funciona a través de un servidor web recibiendo 
peticiones HTTP, y almacena solo datos de forma relacional, no guarda las páginas
HTML, usando un lenguaje de base ya sea PHP,python o Node.js construyendo el sitio 
web

## **Tipos** 

- Open Source: WordPress,Joomla
- De pago: Shopify, Wix 

- Monoliticos
- Desacoplados

## **Ejemplos**

- WordPress: Flexibilidad
- Joomla: Comunidad
- Drupal: Seguridad
- Shopify: Ventas
- Wix: Simplicidad
- Squarespace: Estética
- Webflow: Diseño
- Strapi: Libertad
- Contentful: Escalabilidad
- Storyblok: Visual

## Tabla

| Aspecto | CMS dinámico | Generador estático |
|---|---|---|
| **Forma de crear contenidos** | Usando un panel visual | Mediante código y archivos de texto |
| **Base de datos** | Suele utilizar una base de datos | Normalmente no requiere una base de datos |
| **Generación del HTML** | Se genera cuando el usuario ingresa a la página | Se crea antes de la publicación de la web |
| **Servidor necesario** | Depende de un servidor que procese el contenido | Normalmente no necesita procesamiento en el servidor |
| **Panel de administración** | Está incluido | No suele estar incluido |
| **Conocimientos técnicos** | No requiere muchos conocimientos técnicos | Se requieren conocimientos previos |
| **Seguridad** | Puede tener más puntos vulnerables a ataques | Tiene menos puntos de ataque al no depender de una base de datos |
| **Rendimiento** | Puede ser más lento al procesar la información | Es más rápido porque las páginas ya están creadas |
| **Actualización del contenido** | Se puede realizar mediante un panel de administración | Se debe modificar el contenido y volver a publicar la página |
| **Publicación** | Se utiliza el propio CMS | Se generan los archivos y luego se suben al servidor |
| **Ejemplos** | WordPress, Drupal y PrestaShop | Hugo, Jekyll y Astro |
